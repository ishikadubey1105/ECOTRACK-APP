# EcoTrack

EcoTrack is a fully interactive, custom-engineered, gamified carbon tracker designed to help individuals log, understand, and dramatically reduce their daily carbon emissions. Boasting premium styling, real-time gamified tracking, what-if simulations, and personalized generative environmental advice, EcoTrack empowers users to live more sustainably.

---

## 🚀 Core Features & Modules

### 1. Dynamic Carbon Budget
* **Visual Gauge & Meter**: A beautifully rendered visual indicator tracking your carbon spent against your custom weekly footprint target.
* **Progress Reports**: Direct-sharing module allowing you to export carbon budget performance, streaks, and ecological equivalencies.

### 2. Choice-Based Logging
* **Activity Comparisons**: Interactive side-by-side selectors detailing high-impact vs. low-impact daily choices (e.g., public transit vs. driving, vegetarian meals vs. red meat).
* **Instant Logging Tracker**: Immediate recalculations updating carbon balances and levels on logging activity.

### 3. Gamification & Active Challenges
* **XP Tracking**: Multi-level visual progressions and customizable environmental titles mapped directly to eco-actions.
* **Habit Streaks**: Consecutive activity trackers pushing rewards for daily green habits.
* **Live Badges & Achievements**: Beautiful feedback alerts celebrating milestones.

### 4. What-If Carbon Reduction Simulator & Eco-Quiz
* **Simulator**: Interactive multipliers adjusting real-meat choices, appliance vampire draws, and transport usage to forecast prospective savings.
* **Daily Eco-Quizzes**: Staggered high-fidelity trivia segments updating users on climate facts.

### 5. Generative AI Environmental Advice
* **Personalized Insights**: Real-time generative tips detailing custom sustainability strategies based on logged consumption trends.
* **Eco Commitments**: Opt-in milestones for users to sign green pacts and establish goals.

### 6. Comprehensive Transaction Ledger
* **History Log**: Complete transaction tables detailing activity times, precise categorical calculations, and quick deletions.
* **Download & Backup**: Modular exports to download reports or copy performance snippets dynamically.

---

## 🎨 Design Philosophy
* **Adaptive Dark Canvas**: Deep, modern slate accents (`emerald` and `zinc` tones) minimizing visual eye-strain.
* **Responsive Layout**: Native bento-grid modules optimized across micro-mobile viewports and wide-screen desktop displays.
* **Purposive micro-interactions**: Smooth transitions powered by `motion` and custom-paired `lucide-react` aesthetics.

## 🛠️ Setup & Installation

### Prerequisites
* **Node.js** (v18 or higher recommended)
* **npm** or similar package managers

### Installation
1. Clone this repository to your local directory:
   ```bash
   git clone <your-repository-url>
   cd ecotrack
   ```
2. Install the necessary dependencies:
   ```bash
   npm install
   ```

### Running Locally
To start the application in development mode:
```bash
npm run dev
```

To build and compile package bundles for production:
```bash
npm run build
npm run start
```
